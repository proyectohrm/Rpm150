RPM Moto 150 - PWA

IMPORTANTE:
Los navegadores Android normalmente sólo permiten usar el micrófono en páginas servidas por HTTPS
(o desde localhost). Abrir index.html directamente desde "Archivos" puede no permitir el micrófono.

Forma sencilla:
1. Subir esta carpeta a un hosting HTTPS gratuito (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Abrir la URL con Chrome en Android.
3. Pulsar "Iniciar" y permitir el micrófono.
4. Menú de Chrome > Agregar a pantalla de inicio / Instalar aplicación.

Uso:
- Empezar con "1 pulso por vuelta".
- Moto al ralentí debería mostrar aproximadamente 1200-1800 RPM.
- Si muestra aproximadamente la mitad o el doble, cambiar el modo de pulsos.
- La estimación por sonido no será tan exacta como un captor inductivo.
- Para calibrar, probar primero sin reproducir el sonido de 600.
